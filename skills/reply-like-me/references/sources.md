# Sources

What setup can read, and how to find only the user's own writing in each. Use
whatever connector or tool the session has for a source. Names differ between
Claude Code, Cursor and each connector, so match by what a tool does (searches
Slack messages, reads a Drive file), not by its exact name.

| Source | Kind | Shows | Needs |
| --- | --- | --- | --- |
| Slack | Chat | Quick voice with the team | A Slack search tool that covers DMs and private channels |
| Microsoft Teams | Chat | Quick voice with the team | A Teams or Microsoft 365 tool that searches chat and channel messages |
| Google Chat | Chat | Quick voice with the team | A Google Chat tool |
| Discord | Chat | Quick voice, often outside work | A Discord tool, or an exported chat |
| Gmail | Email | Voice with outsiders and seniors | A Gmail tool that searches sent mail |
| Outlook | Email | Voice with outsiders and seniors | An Outlook or Microsoft 365 mail tool |
| Google Docs | Docs | Long-form voice | Google Drive search and read tools |
| Confluence | Docs | Long-form voice | A Confluence search and read tool |
| Notion | Docs | Long-form voice | A Notion search and read tool |
| Word in OneDrive or SharePoint | Docs | Long-form voice | A OneDrive or SharePoint tool |
| Files | Any | Whatever the user exports | Paths the user gives you |

## Chat

**Slack.** The search tool usually reports the user's ID. Search
`from:<@ID>` with `after:` and `before:` dates, sorted by time, and page with
the cursor. Restrict by channel type to separate DMs and group DMs from
channels.

**Microsoft Teams.** The user's identity is their work email address, which
the Microsoft 365 tool usually reports for the signed-in account. Search
messages sent from that address, split into chats (1:1
and group) and channel posts. Teams search often returns the whole
conversation, so keep only messages where the sender is the user. Skip meeting
chat that is only links and "joined the call".

**Google Chat.** Search messages from the user. Direct messages count as DM,
spaces as CHANNEL.

**Discord.** Usually personal rather than work. Ask before including it, and
keep it to the servers the user names.

## Email

**Gmail.** Search `in:sent` with `after:` and `before:` dates. **Outlook.**
Read the Sent Items folder by date range, using the signed-in account.

For both: keep only what the user wrote. Cut quoted replies (lines after "On
... wrote:" or "From:"), forwarded text and signatures. Skip calendar replies,
out-of-office notices, auto-replies and newsletters. Note the greeting and the
sign-off, because email is where people use them. Split by recipient: inside
the company or outside it.

## Docs

**Google Docs.** Search for documents the user owns, by date and keyword.
Meeting notes generated by Gemini or another assistant are titled "Notes by
...": skip them.

**Confluence.** Search pages the user created, by date and space. Skip meeting
notes templates, page trees of how-to steps and pages mostly edited by others.

**Notion.** Search pages the user created. Skip databases, task lists and
meeting templates.

**Word in OneDrive or SharePoint.** Search documents the user authored. Skip
templates and shared documents that others mostly wrote.

## Files

Ask the user for a folder or an export. Slack and Teams exports are JSON:
keep only messages whose sender is the user. Text and Markdown files are
read as docs. Never upload the files anywhere.

## Signs of AI-written text in any source

- A footer naming an assistant: "Sent using ...", "Drafted with ...",
  "Generated by ...".
- Em dashes, especially in someone who otherwise uses hyphens.
- Tidy, evenly sized paragraphs or bullets with bold labels, in a person who
  otherwise writes loosely.
- Stock words: delve, robust, seamless, comprehensive, leverage, underscores,
  fosters, "It is not X. It is Y.", "In short".
- A sudden change in register in the same week or thread.
